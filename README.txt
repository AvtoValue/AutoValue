AutoValue — early web app prototype

Open index.html in a modern browser. You can choose a country and language, choose Buy or Sell, enter vehicle details, and preview a report layout.

Important limitations:
- No live vehicle listings are fetched.
- No AI API, VIN decoder, backend, database, accounts, or real photo analysis are connected.
- No market valuation is fabricated.
- Each portal must be integrated only through permitted APIs, approved access, or a data agreement.
- Do not put API keys in browser code. A production version needs a secure backend and data source agreements.
